1. Introduction
Pro17 Analytics is committed to protecting user privacy and maintaining appropriate data security practices.
This Privacy Policy describes how the Pro17 Treemap Custom Visual for Microsoft Power BI (the "Visual") processes and handles information during its operation.
This policy applies specifically to the Visual and is separate from the Pro17 Analytics website privacy policy.
2. Data Collection and Processing
Depending on the fields and measures configured by the report author, the Visual may process:
•	Category and hierarchy values
•	Numerical measures and aggregated data
•	Report filtering and selection information
•	Drill-down and navigation context
•	User-entered analytical questions
The Visual uses this information to provide visualization and analytical functionality.
3. Purpose of Data Processing
The Visual processes information to support:
•	Interactive hierarchical Treemap charts
•	Drill-down and category navigation
•	Aggregations and calculations
•	Data filtering and sorting
•	Detailed information in table view
•	Category-based analytical results
•	User-initiated CSV and PDF exports
4. Analytical Assistant
The Visual includes a built-in analytical assistant that supports questions about the data available to the Visual.
Its current local rule-based implementation supports:
•	Category listings and counts
•	Top and Bottom N rankings
•	Totals and averages
•	Basic analytical summaries
Verification pending: Before publication, the production implementation must be reviewed to determine whether analytical questions or report data are transmitted to external services.
5. Data Storage and Retention
The Visual processes Power BI report data during its operation.
Whether report data, analytical questions, user preferences, or diagnostic information are stored or retained must be confirmed against the production implementation.
The final approved policy must describe any applicable storage mechanisms, retention periods, and deletion practices.
6. Data Sharing and External Services
The Visual is designed for use within Microsoft Power BI.
Any external network connections, service providers, or transfers of report data must be identified and documented before publication.
The approved policy must disclose any applicable external data-processing arrangements.
7. Data Export
The Visual provides user-initiated CSV and PDF export functionality.
Exported files may contain information from the user's Power BI dataset.
Users and organizations are responsible for managing exported information in accordance with applicable data protection and security requirements.
8. Data Security
Pro17 Analytics aims to apply appropriate technical and organizational safeguards to the Visual.
The Visual operates within Microsoft Power BI and relies on applicable platform permissions and access controls.
The production package must be reviewed to confirm its permissions, external connections, and relevant data-handling behavior.
9. User Responsibilities
Users and report authors are responsible for ensuring that they have appropriate authorization to process information supplied to the Visual.
Organizations should configure access permissions and data protection controls according to their applicable requirements.
10. Changes to This Privacy Policy
Pro17 Analytics may update this Privacy Policy to reflect changes in the Visual, its data-processing practices, or applicable legal requirements.
Updated versions will identify their effective date.
