# Pro17 Treemap Matrix Custom Visual – Support

## Product Information

Product: Pro17 Treemap Matrix Custom Visual
Publisher: Pro17 Analytics
Platform: Microsoft Power BI

## Overview

The Pro17 Treemap Matrix Custom Visual provides hierarchical data visualization, drill-down navigation, customizable legends, filtering, table view, data export, and AI-assisted analysis features.

## Installation

1. Open Microsoft Power BI Desktop.
2. Open the Visualizations pane.
3. Select Get more visuals.
4. Search for Pro17 Treemap Matrix Custom Visual once it is published.
5. Add the visual to your report.
6. Assign category and measure fields.

## Troubleshooting

If the visual does not display data, verify the category and measure field assignments, data types, and applied filters.
